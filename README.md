# عيادة بسمة الحياة البيطرية — Smile Life Pet Clinic (Demo)

نسخة عرض (واجهة أمامية) لموقع **عيادة بسمة الحياة البيطرية** في السويدي، الرياض. Vue 3 + Vite، عربي/إنجليزي.

## التشغيل
```bash
npm install
npm run dev
```
الرفع على Vercel: GitHub ثم Import (Build: `npm run build`، Output: `dist`).

## الأصول (`public/img/`)
كلها من صور العيادة على خرائط Google: الواجهة ليلاً، الاستقبال وشعار الختم، صالة الانتظار، غرفة الحلاقة، المتجر، المكافآت، مكتب الاستقبال، وصور المرضى (قطط أثناء العلاج والحلاقة).
استبعدت صوراً مرفوعة على صفحتهم لعيادات أخرى (لقاء القطط، الزياد، …) وصور الجروح والعمليات.

الشعار (`LogoBadge.vue`) مرسوم SVG على شكل ختمهم الدائري: "SMILE LIFE PET CLINIC — EVERY PET HAS A SMILE" مع قط وكلب وقلب.
موقعهم الحالي smilelifevet.com لا يفتح عبر HTTPS. لم أجد حساب سوشيال ميديا ظاهراً لهم.

## المحتوى
- عرض "خصم 20% على عمليات التعقيم والإخصاء" مأخوذ من لوحة على مكتب الاستقبال في صورهم — تأكد أنه ما زال سارياً.
- "التطعيمات" خدمة مفترضة (معتادة في العيادات) — تأكد منها.
- د. إسلام هو أكثر اسم يتكرر في المراجعات.
- أوقات العمل والهاتف والعنوان من خرائط Google.

## قبل الإطلاق الرسمي
احذف `noindex` من `index.html` وشريط "نسخة عرض" من `src/App.vue`.
